# Detecção de anomalias

> **Situação:** minuta para discussão pública. **Versão:** 0.1. **Data:** 2026-11-07.

Um alerta estatístico indica que um registro difere de um padrão definido. Não equivale a acusação, prova de fraude ou decisão jurídica.

Os detectores devem registrar versão do algoritmo, dados utilizados, critérios de corte, taxa de falsos positivos conhecida e exemplos de explicações legítimas para o padrão encontrado.

A priorização deve considerar relevância pública, impacto, confiabilidade das fontes e possibilidade de verificação. A divulgação de casos individuais exige revisão adicional.
