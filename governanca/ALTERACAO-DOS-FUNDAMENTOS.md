# Alteração dos fundamentos

> **Situação:** minuta para discussão pública. **Versão:** 0.1. **Data:** 2026-11-07.

Correções materiais simples podem seguir processo editorial ordinário. Mudanças de missão, independência, proteção de fontes ou direitos fundamentais deverão exigir procedimento reforçado.

Toda alteração deve indicar justificativa, comparação de versões, data e responsáveis pela aprovação quando houver estrutura instituída.

Não é admissível apagar versões antigas para disfarçar mudanças de posição. Quando necessário, dados pessoais serão protegidos no histórico público.
