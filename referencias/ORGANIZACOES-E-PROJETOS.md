# Organizações e projetos semelhantes

> **Situação:** minuta para discussão pública. **Versão:** 0.1. **Data:** 2026-11-07.

O objetivo desta lista é identificar experiências que podem orientar a construção do Rondoscópio sem reproduzir suas marcas ou atribuir-lhes participação no projeto.

| Organização ou projeto | Área de referência |
| --- | --- |

| [Intercept Brasil](https://www.intercept.com.br/) | Investigação, fontes e relações de poder |
| [ProPublica](https://www.propublica.org/) | Apuração e ética editorial |
| [OCCRP](https://www.occrp.org/) | Investigação de corrupção e documentos |
| [ICIJ](https://www.icij.org/) | Dados societários e colaboração |
| [Bellingcat](https://www.bellingcat.com/) | OSINT e verificação |
| [InfoAmazonia](https://infoamazonia.org/) | Mapas e investigação amazônica |
| [Transparência Brasil](https://www.transparencia.org.br/) | Controle social e contratos |
| [Observatório Social do Brasil](https://www.osbrasil.org.br/) | Fiscalização e educação municipal |
| [MuckRock](https://www.muckrock.com/) | Lei de acesso, pedidos e documentos |
| [Querido Diário](https://queridodiario.org.br/) | Diários oficiais e coleta |
