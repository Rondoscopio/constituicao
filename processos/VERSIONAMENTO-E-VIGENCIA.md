# Versionamento e vigência

> **Situação:** minuta para discussão pública. **Versão:** 0.1. **Data:** 2026-11-07.

Datas, versões e estado deverão constar dos documentos. O histórico do Git é complementar, não substitui a indicação explícita de vigência.

Uma correção gramatical pode ter registro simples. Alterações substantivas precisam indicar o conteúdo modificado e a justificativa.

A conservação de versões antigas não poderá causar divulgação indevida de dados pessoais sensíveis.
